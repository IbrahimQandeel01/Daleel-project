# Daleel Project

**AI-Powered Legal Chatbot Using Retrieval-Augmented Generation (RAG)**

Daleel is an advanced AI chatbot designed to provide accurate and context-aware legal information. Leveraging the Retrieval-Augmented Generation (RAG) system, it answers a wide array of legal queries by retrieving relevant documents and generating precise responses.

---

## 🚀 Features

* **Legal Query Handling**: Efficiently processes and responds to various legal questions.
* **RAG Integration**: Utilizes a hybrid approach combining document retrieval and generative AI for enhanced accuracy.
* **User-Friendly Interface**: Designed for seamless interaction and easy access to legal information.
* **Scalable Architecture**: Built to handle a growing database of legal documents and user queries.

---

## 🛠️ Technologies Used

* **Backend**: Java 17, Spring Boot, Gradle
* **Frontend**: HTML, CSS, JavaScript (No React used)
* **Database**: Not utilized in this project
* **APIs**: RESTful APIs

## ⚙️ Setup & Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/IbrahimQandeel01/Daleel-project.git
   cd Daleel-project
   ```

2. **Backend Setup**:

   ```bash
   ./mvnw clean install
   ```

3. **Frontend Setup**:

   Navigate to the `Daleel-front-end-main` directory and follow the frontend setup instructions provided there.
